# Biblioteca Digital

Aplicación web desarrollada en Java usando JSP y Servlets para gestionar libros de una biblioteca.

## Tecnologías utilizadas

- Java
- JSP
- Servlets
- Apache Tomcat
- MySQL
- Eclipse IDE

## Requisitos

- JDK 8 o superior
- Apache Tomcat
- MySQL Server
- Eclipse IDE

## Configuración de la base de datos

1. Crear base de datos:

CREATE DATABASE biblioteca;

2. Crear tablas necesarias:

usuarios
libros

3. Insertar usuario de prueba:

usuario: admin
password: 1234

## Ejecución del proyecto

1. Importar el proyecto en Eclipse.
2. Configurar Apache Tomcat como servidor.
3. Ejecutar el proyecto con:

Run As → Run on Server

4. Abrir en el navegador:

http://localhost:8080/BibliotecaDigital

## Funcionalidades

- Login de usuario
- Conexión a base de datos
- Visualización de libros
- Interfaz web con CSS responsivo
